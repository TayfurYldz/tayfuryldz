# Contribution graph art — safe setup notes

The green GitHub contribution grid is not an image layer. Each square reflects contribution activity for a date, so “drawing” directly on that grid means creating dated contributions.

For this profile, the recommended order is:

1. Ship the profile README and animated SVG hero first.
2. Keep real project repositories untouched.
3. If contribution-grid pixel art is desired, use a dedicated public repository created specifically for that visual experiment.
4. Make the pattern obvious as profile art rather than pretending the commits represent project work.

A less artificial alternative is an animated contribution-snake SVG generated from real activity and embedded in the profile README.
